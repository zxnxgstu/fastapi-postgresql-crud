# FastAPI PostgreSQL CRUD

Simple CRUD API built with FastAPI, PostgreSQL and SQLAlchemy.

## Features

- Get all products
- Get product by ID
- Create product
- Update product
- Delete product
- PostgreSQL database
- SQLAlchemy ORM
- Swagger documentation

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- Uvicorn
